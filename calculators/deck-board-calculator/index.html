About this deck board calculator

A deck is just rows of boards. Count the rows (deck width divided by board width), multiply by the deck length, and divide by the board length you are buying — that is your board count. The calculator does exactly this, then adds waste for end cuts and the occasional split board.

Board width deserves a real measurement. A nominal "6-inch" deck board is actually 5.5 inches wide, and that half inch compounds across 20+ rows into a meaningful difference. Composite boards vary by manufacturer — check the spec sheet.

Two things this count excludes: the picture-frame border (perimeter boards running perpendicular — measure the perimeter separately) and stairs (each tread is roughly one board width times stair width, times the number of steps). Add both manually.

How to use

  1. Measure the deck length (the direction boards will run) and deck width in feet.
  2. Choose the board length you plan to buy — longer boards mean fewer butt joints.
  3. Enter the actual board width in inches (5.5 for nominal 6-inch boards).
  4. Press Calculate. Add border boards and stair treads separately.

Good to know

  • Excludes picture-frame borders, stairs, fascia boards, and railing — all separate material lists.
  • Assumes boards run straight and parallel; diagonal decking needs ~15% waste.
  • Joists, beams, posts, and hardware are structural — size them per local code and span tables, not this calculator.

Frequently asked questions

How many deck boards do I need for a 12x16 deck?

With 5.5-inch boards running the 16 ft direction: 12 ft width ÷ 5.5 in ≈ 27 rows × 16 ft ÷ 16 ft boards = 27 boards, plus 10% waste ≈ 30 boards of 16 ft.

What size boards are used for decking?

Most residential decks use 5/4×6 (actual 1×5.5 in) or 2×6 (actual 1.5×5.5 in) boards in 8–20 ft lengths. Composite boards come in similar profiles.

How far apart should deck boards be spaced?

A 1/8 to 1/4 inch gap for drainage and expansion. The calculator's row count uses board width; the gap is absorbed in the waste allowance.

How do you calculate decking?

Rows = deck width ÷ board width; boards = rows × deck length ÷ board length; add 10% waste.

Should deck boards run parallel to the house?

Usually perpendicular to the house (running out from it) looks best and sheds water away, but either works structurally if joist spacing is correct.
